# Distortion waves

[Source](https://x.com/jakubantalik/status/2120204589131870610) by Jakub Antalik.
Saved November 11, 2026. [Watch the clip](clip.mp4), 8.17 seconds.

A payment confirmation sends a luminous distortion wave across the screen. A second example
contains the effect within a smaller card. The interface settles back into a quiet success state.
The author describes two wave types, anticipation movement, particles, and wave direction based
on the touch point.

Reference for future Agent animations. Keep the contrast between a calm interface and a brief,
expressive response to an action. Explore this for meaningful completion moments.
