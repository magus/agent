# chatgpt-login

## Context

Add the next small proof using the dcssweb login implementation as a reference. Prove ChatGPT
login and one subscription-backed model request before building the agent loop.

## Decisions

- Use the documented local-app registration flow with Agent's own client identity. The dcssweb
  reference predates this flow and uses the Codex client and backend endpoint.
- Keep the first proof to one saved account, browser login, Keychain storage, token refresh, and a
  harmless model request. Do not add desktop actions or silently fall back to API billing.

## Changes

- Added the Rust ChatGPT client and a GPUI account window, available from Agent → ChatGPT.
- Login uses fresh state, nonce, and PKCE, a loopback listener, validated ID tokens, and Agent's
  dynamically issued client ID. Tokens stay in macOS Keychain. No Codex credentials are read.
- Added a model check that discovers the account's model catalog and requests `9 × 221` as a
  tool call. It requires a completed response and never uses an API key.
- Added local sign-out, remote revocation attempt, expiry refresh, cancellation, and usage link.
- Updated the agent-core plan. Screenshot inference and the task loop remain separate work.
- Account reload errors now appear in the UI instead of being silently ignored.

## Verification

- Read dcssweb's research note and refresh/request implementation.
- Read official local-app registration, session renewal, and model-request documentation.

- Four tests passed for callback binding, denied login, incomplete streams, plan scope, and refresh
  token rotation. Clippy and the signed local build passed.
- The user approved Agent through ChatGPT. Agent received the loopback callback, validated the
  identity, and saved the session in Keychain. The browser's plain callback page was expected.
- The initial window showed contradictory account status. Restarting loaded the saved account
  without another login. The exact cause of the initial display is not established.
- The live model check discovered `gpt-6.1-sol` and received `1989` through a completed tool call.
  It used the saved ChatGPT token and sent no API key. No desktop image or action was sent.
- Formatting, Clippy, and all four tests passed after the error-display change.
- The final signed build passed notarization and ticket validation. Apple accepted submission
  `282673bf-5f6d-4684-b9cf-4eb5a3e6d29c`. The app is at `dist/Agent.app`.
