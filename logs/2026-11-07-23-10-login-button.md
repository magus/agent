# login-button

## Context

Apply the requested callback typography and natural width. Show login progress and the OpenAI
logo in the existing GPUI button.

## Decisions

- Use the button's built-in loading spinner, replacing the idle icon while signing in.
- Bundle the logo rather than fetching it at runtime. The SVG comes from Simple Icons 15.0.0,
  https://cdn.jsdelivr.net/npm/simple-icons@15.0.0/icons/openai.svg. OpenAI owns the mark.

## Changes

- Callback headings use weight 200 and instructions use weight 400. Removed the strong element
  and main width constraint. Updated every previously shared preview.
- The login button shows the OpenAI logo when idle. While signing in it shows a spinner and
  Waiting for ChatGPT, stays disabled, and retains the existing cancel action.
