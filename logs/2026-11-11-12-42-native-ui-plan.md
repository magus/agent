# Native UI migration

## Context

Replace GPUI with native Mac and iPhone interfaces. The migration is complete; remaining checks
are in `TODO.md`. Keep Rust application behavior shared through static libraries.
Preserve the existing Agent identity, credentials, grants, conversations, and request IDs.
Physical-phone interaction is deferred at the user's request. Simulator checks are required now.

## Decisions

- Consolidate Apple build orchestration in Python, including plist handling and signing. Keep the
  existing Mac shell command only as a forwarding entry point with no build logic.

- Remove the unused app-level permission diagnostic command and move the macOS helper to
  `src/desktop_service/`, as approved. Keep its internal `--permissions` mode for tool checks
  and the native setup window.

- Group native sources under `src/clients/apple/`, with shared feature folders and separate macOS
  and iOS startup. Keep the desktop helper at `src/agent/app/desktop_service/` for now, as requested.
  Move shared Rust client behavior from `app/` to `client/`.

- Keep the broader source layout unchanged while discussing client ownership and separate platform
  entry points. Prefer dedicated platform implementations when shared code needs many conditions.

- Noah approved controlled missing/revoked-permission testing on the mini. Test one permission
  at a time, restore both, and verify locked control afterward. Do not modify the TCC database or
  create a new app identity. The mini's grants remain enabled until a separate recovery path is ready.

- Noah deferred full VoiceOver testing on November 20 because it is excessive for this migration.
  Keep it as a follow-up. Restored his VoiceOver setting to off and verified the switch.

- Rust owns networking, pairing, central authentication, delivery, retry, and persistence. Swift
  owns presentation, platform integration, and per-conversation drafts. The central service stays
  independent. The iPhone is a client and advertises no local execution tools.
- Use the existing approved Agent identities. Do not create one-off permission apps or reset real
  grants to test negative cases. Credentials must never enter tool output.
- Use Agent's paired shell connection for mini maintenance. SSH-independent update and recovery
  gaps are tracked separately in `docs/plans/remote-maintenance/README.md`.
- Use locally bundled Pierre Words for Markdown, as requested. The earlier Foundation parser was
  removed, not retained as a fallback. Native hosting checks remain part of the migration.
- The reported scroll freeze was real. Main-thread samples on both platforms showed repeated
  SwiftUI lazy layout. Deferring scroll corrections alone did not fix it. A regular message stack
  now passes the reproduced interactions; its larger-history resource cost remains under review.

## Changes

- Replaced `packaging/apple/build.sh` with `build.py`. iPhone signing is now an imported Python
  module. Bundle assembly, compilation, signing, notarization, and optional dist publication all
  run from Python. Updated native build instructions.

- Removed completed Markdown, chat UI, and native UI plans. Kept physical-phone, touch-selection,
  deferred VoiceOver, and startup-memory follow-ups in `TODO.md`. Folded capture-confirmation work
  into the desktop-permissions plan. Moved central-service operating instructions to
  `docs/central-service.md` and removed its completed checklist. Updated current documentation links;
  historical log references remain unchanged.

- Removed `diagnose.rs` and the app-level `--permissions` argument, dispatch, and documentation.
  Moved the helper sources and README to `src/desktop_service/` and removed the remaining `app/`
  module. Updated packaging and documentation links. Tool and setup-window permission probes
  still call the helper’s unchanged internal `--permissions` mode.

- Moved shared Rust client code into `src/agent/client/` and native sources into
  `src/clients/apple/`. Mac and iPhone now have separate app entry points. Shared feature code
  lives under `shared/`; the build selects only the relevant platform startup files. The desktop
  helper remains in its existing location. Updated build paths and current documentation.

- Renamed the Swift `Client/` folder to `Bridge/`. Moved `Conversation.swift` and
  `ModelSettings.swift` into `Chat/` and updated the native build paths. Runtime behavior is unchanged.

- Removed the GPUI windows, menus, adapters, and dependency after native interaction checks.
  Shared Rust clients, login callbacks, device transport, and the independent service remain.
  `packaging/macos/app.sh` now builds the native app through the Apple build script and copies it
  to `dist/Agent.app`. Final builds and deployment checks are in progress.

- Markdown keeps a stable native container and measured height while releasing its offscreen WebKit
  renderer. Each message renders once before release. A small positive visibility threshold excludes
  fully offscreen rows. VoiceOver keeps renderers available for accessibility navigation. Stale
  callbacks from released views cannot update heights. The regular SwiftUI stack stays unchanged.

- Closing the native permission preview now cancels its task. If capture finishes after the window
  closes, the task deletes that late screenshot instead of keeping an unseen temporary file.

- Reload a terminated WebKit content process and render the retained message again. Keep its
  measured native height while recovering so an OS renderer termination does not leave a blank row.
  Both Mac and Simulator builds pass; controlled termination has been verified on both platforms.

- Native startup now awaits client initialization and the first snapshot before opening a requested
  setup sheet. The live `--devices` check had exposed a stale initialization error caused by opening
  its polling view too early.

- Skip unchanged conversation, sidebar, and pending-message assignments during native polling.
  These data types now support equality, avoiding repeated view invalidation while idle.

- Added `src/apple/` native interfaces and `packaging/apple/` builds for Mac, Simulator, and iPhone.
  The native entry point dispatches existing command modes before starting SwiftUI. The bundle
  includes an independent `agent_service` executable and the existing Swift desktop helper.
- Added a shared Rust static library and a small C bridge. The native clients now replace GPUI.
  iPhone builds exclude desktop commands and the Mac administration socket.
- Moved persisted pending-delivery and retry behavior into Rust. Messages retain their original
  ID, text, service, conversation, and settings. Failed sends do not overwrite newer drafts.
  Selecting a conversation changes its draft immediately and ignores stale snapshots.
- Added native composer, model/effort controls, conversation defaults, device badges, collapsed
  tool rows, screenshot sheets, service connection, device management, and central ChatGPT setup.
  iPhone model controls stack vertically when horizontal space is insufficient.
- Native login cancellation clears pending state immediately. Attempt IDs prevent old callbacks
  from completing or overwriting newer attempts. Mac uses the browser; iPhone uses a system
  authentication session. The service owns the resulting credentials.
- Fixed response buffering in the central client. It now reads streamed events and publishes
  in-memory text previews. Completion replaces the preview; failure and cancellation clear it.
  Partial text never enters saved model input or triggers tools.
- Added the local Words WebKit host, syntax highlighting, licenses, and content restrictions.
  Remote images and executable model HTML are blocked. Explicit HTTP, HTTPS, and mail links open
  externally. Screenshot viewing remains native. Quotes retain readable text in dark mode.
- Scroll following uses an explicit end marker and deferred corrections after Markdown measurement.
  Scrolling away disables following; the overlay arrow returns to the latest message. Native
  navigation links fix reopening the already-selected conversation on iPhone.
- Added a passive touchstart listener after diagnosing WebKit interception of code-block drags.
  Temporary gesture logging, CSS touch-action experiments, and UIKit handoff experiments were
  removed. Mac WebKit forwards vertical wheel events to the native conversation.
- Sharing a nonpersistent WebKit store did not reduce renderer process count and was reverted.
  Visibility-based creation reduced seven Simulator renderer processes to one, but caused scroll
  jumps when messages reloaded. Measuring each message before releasing its renderer did not
  resolve the jumps. That experiment was also removed. Keep the stable eager rendering while
  finding a resource strategy that preserves layout and selection.
- Removing the scroll-target modifier from lazy rows passed the Mac scroll check, but the
  Simulator's return-to-latest control landed on a persistent blank area. Seven renderers also
  remained alive, so it did not establish a memory improvement. Reverted this experiment, rebuilt
  both platforms, and restored the running apps. The Simulator again scrolls and returns to line
  200. The Simulator's text size has since been restored to its original setting.
- Desktop setup opens System Settings explicitly. Discovery uses silent permission checks and
  keeps shell availability separate. Native supervision restarts the bundled helper.
