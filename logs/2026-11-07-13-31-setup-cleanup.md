## Context

## Decisions

- Keep the working desktop service and GPUI interface. Do not build a model loop in this delivery.
- The next phase must include ChatGPT login and use eligible subscription quota, without requiring
  an API key. Verify the supported integration before choosing the model connection.

## Changes

- Separated permission-check errors from capture messages so recovered probes clear their errors.
  Failed probes show Unavailable instead of remaining at Checking.
- Made each temporary preview own its image file. Dropping a preview, or closing setup before its
  async result arrives, releases the file. Confirmation also clears an earlier save error.
- Split the UI into named sections. Kept long error content scrollable and hid the repeated setup
  hint while a preview is visible. Kept the required native redraw fix; no debug prints remain.
- Added `docs/plans/agent-core/README.md` with ChatGPT login, subscription usage, a first model request,
  and the later vision-only task loop. Linked official login documentation without choosing an
  integration or implementing model access.
